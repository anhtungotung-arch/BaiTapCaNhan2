# BaiTapCaNhan2

## 1. Giới thiệu
**IP Address Analyzer** là chương trình phân tích địa chỉ IP, hỗ trợ tìm hiểu thông tin và các đặc điểm cơ bản của địa chỉ IP.

## 2. Chức năng
- Phân tích địa chỉ IP.
- Kiểm tra tính hợp lệ của địa chỉ IP.
- Hiển thị kết quả phân tích.

## 3. Cấu trúc project
- `IP_Address_Analyzer/`: Thư mục chứa mã nguồn chương trình.
- `README.md`: Tài liệu giới thiệu project.

## 4. Mục đích
Project được thực hiện nhằm phục vụ việc học tập và thực hành lập trình.
